# Small model results

Generated by `scripts/slm_results.py` from `runs/` and `results/train_logs/`. Every small-model run here is scored in bf16 on the full eval set. `E1000` is the first 1,000 L2DTnH test messages, scored against the expert annotators (102 toxic). The pressure set is 40 hard lines, 4 for each of 10 kinds, labelled by the author under [docs/LABELING_RULES.md](../docs/LABELING_RULES.md) (11 toxic, 29 not). Bar, set before any run: precision ≥ 0.80 and F1 ≥ 0.75 on `E1000`. A reply counts only if it is exactly `toxic` or `nontoxic`; anything else is scored wrong.
